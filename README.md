# PC Price Tracker

A lightweight web application for keeping track of PC products and eBay listings that you are interested in purchasing.

Users can add a product, record its price, and save the corresponding eBay auction link for quick access later.

## Features

* Add products to a personal tracking list
* Record product prices
* Store eBay auction links
* View tracked products in one place
* Quickly access saved listings
* Simple, lightweight web interface

## How It Works

The application allows users to enter information about a product they are interested in purchasing.

For each product, the user can provide:

* Product name
* Price
* eBay auction link

The information is then displayed in the tracker so the user can easily return to the listing later.

## Technologies

* **HTML** — Page structure and user interface
* **CSS** — Styling and layout
* **JavaScript** — User interaction and product tracking functionality

## Getting Started

No installation or external dependencies are required.

Clone the repository and open `index.html` in a web browser:

```bash
git clone https://github.com/AminCharepoo/Product-Tracker.git
cd Product-Tracker
```

Then open `index.html` in your browser.
